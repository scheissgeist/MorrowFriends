# Play Morrowind together

Windows. Setup is once, and there is no Tailscale any more.

## What you need

- Morrowind Game of the Year Edition from Steam or GOG (includes Tribunal and
  Bloodmoon).
- The MorrowFriends ZIP from the host or from
  [GitHub Releases](https://github.com/scheissgeist/MorrowFriends/releases/latest).

That is the whole list. No accounts, no invite links, no network setup.

## 1. Open MorrowFriends

1. Right-click the ZIP and choose **Extract All**. Put the extracted
   `MorrowFriends` folder somewhere easy to find.
2. Open that folder and double-click `MorrowFriends.bat`.
3. Windows may ask whether to run it. Click **More info**, then
   **Run anyway**.
4. Wait for the top of the launcher to say Morrowind GOTY was found.
5. If it was not found, click **Change** and pick either your Morrowind
   folder or its `Data Files` folder.

## 2. Press Play

1. Type your character name under **You are** if you already have one. First
   time: type the name you will create, or leave it blank — the launcher
   fills it in when you log in.
2. Click **Play**.
3. First launch downloads TES3MP (about 62 MB).

MorrowFriends connects to the party server on its own. There is no server
password.

## 3. Create your character

1. Choose a unique name.
2. Create a character password when TES3MP asks. **Write it down** — you need
   the same one every time you play this character.
3. Finish Morrowind's normal character creation.

If you forget it, the host can reset it from the admin panel without losing
your character.

## 4. Voice

Play opens voice **in this window** after your character loads (or right
away if **You are** is already filled). Allow microphone access once.
**Back** returns to Play; the call keeps running. **Open voice** does the
same thing if you skipped it.

- Push-to-talk defaults to **Space**. Change it under the gear → **Push-to-talk**.
  Any key, or a mouse button. It works while Morrowind has focus.
- To skip voice, turn off **Join voice when I play** in the gear. **Open voice**
  still works if you want it this session.
- Keep MorrowFriends running while you play; it powers push-to-talk while
  Morrowind has focus.
- Voice is proximity based: people close by are louder, interiors are separate
  rooms, and distance fades you out.
- The small **Nearby** strip is a separate overlay on top of the game for
  `/goto`. It is not the voice chat.

## Rules on this server

- **Crime is personal.** If you murder someone, guards hunt *you*, not the
  party.
- Quest progress, faction ranks, and dialogue topics are **shared** — everyone
  advances the story together.
- Map exploration is personal; you reveal your own map.

## If something goes wrong

Play shows one **Fix this** button for the next step. Beyond that, the gear
opens Settings in the same window (**Back** returns to Play). It can find
Morrowind, repair TES3MP, install the C++ runtime, or open the voice-position
diagnostic. **Open voice** stays on the Play screen.

Send the host a screenshot if it still fails. Do not spam Play or Repair.
