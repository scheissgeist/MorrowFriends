### Checked and clean (no finding)

  `PANEL_PASS` has no default and locks the panel when unset.
  `MORROWVOICE_HOST_TOKEN`, `LIVEKIT_API_KEY` and `LIVEKIT_API_SECRET` come
  from the environment, and `configure.py` generates them with `secrets` and

## Changes in this PR (tree only)

- No secret values were in the tree, so no code needed an env-var swap.
- `.gitignore`: added generic credential-file patterns (`*.ppk`, `*.jks`,
  `*.keystore`, `id_rsa*`, `id_ecdsa*`, `id_ed25519*`, `.netrc`,
  `credentials*.json`, `*.secret`). No tracked file matches them.
- `voice_service/deploy/.gitignore`: added `*.tmp`, because `configure.py`
  stages `.env` as `.env.tmp` before renaming it, and a crash would leave the
  secrets in that file. The root `.env.*` rule already caught it; this adds
  a second rule where the file lands. Also added `caddy.morrowfriends`, the
  other generated output.

No history was rewritten, no branches or tags were touched, and nothing was
deployed or uploaded.
